# Australian Longevity Explorer

A static, serverless explorer of life expectancy at ages 60 to 90 by socio-economic profile,
hosted free on GitHub Pages at https://auslongevity.org.

- **Public site (`/`):** plain JavaScript in `web/`. It loads in about a second because there is no
  R engine to download.
- **R version (`/r/`):** the original Shiny app in `app/`, compiled with
  [shinylive](https://posit-dev.github.io/r-shinylive/) so it runs in the browser. It is kept as a
  backup and as the reference that the JavaScript version is tested against.
- **Hosted Shiny app:** https://auslongevity.shinyapps.io/explorer/

## Repo layout

- `web/` - the JavaScript site (`index.html`, `style.css`, `core.js`, `app.js`, `data.json`).
- `app/` - the Shiny app source (`app.R` + small data files).
- `data-raw/` - the raw source spreadsheets (ABS SEIFA 2016 and the ALT life tables), plus
  `build_data.R` and `build_web_data.R`, which turn them into the small data files used by `app/` and
  `web/`. Visitors never download the raw files.
- `tests/` - checks that compare the JavaScript with the R app.
- `docs/` - the exported site that GitHub Pages serves. Generated by `build-site.sh`; do not hand-edit.

## Rebuilding the site after a change to `web/` or `app/`

```sh
./build-site.sh
```

This needs R with the `shinylive` package. The script exports the R version to `/r/` (removing
shinylive files it never uses), copies `web/` to the root, and sets the custom domain. Then commit and push the
updated `docs/` folder.

## Static JavaScript version (the public site)

`web/` holds a version of the explorer written in plain JavaScript, with no R engine to download,
so it loads in about a second. It is the public explorer at the root of the site. The R (shinylive)
version is kept at `/r/` as a backup and is hidden from search engines. `/beta/` redirects to the root.

- `web/core.js` holds the calculations (the same steps as `app/app.R`), `web/app.js` the interface,
  and `web/data.json` the data (built by `Rscript data-raw/build_web_data.R`).
- `tests/` checks the JavaScript against the R app. `make_reference.R` writes reference results from
  the R functions, then `node tests/check.mjs <reference.json>` compares them (all 29,760 combinations
  of profile, age and basis, the axis ticks and the postcode handling). `tests/check_text.mjs`
  compares the summary wording with the text the R app renders.

## Notes

- Uses only `shiny` and `dplyr` at run time, with base R graphics and string functions (no
  `tidyverse`, `ggplot2`, `stringr`, `readxl` or `shinyjs`), to keep the WebAssembly package bundle small.
- To refresh the lookup files after changing a raw spreadsheet, run `Rscript data-raw/build_data.R`
  (needs `dplyr` and `readxl`), then re-export the site.
- The R version at `/r/` downloads the R/WebAssembly runtime on the first visit (cached by the
  browser afterwards), so its first load is slow. The JavaScript site does not.
- The life expectancy methodology follows Huang, Hui & Villegas,
  *Australian Retirement Mortality* (JRI submission).
